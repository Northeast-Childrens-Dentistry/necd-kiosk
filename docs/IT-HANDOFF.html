IT HANDOFF · DEBIAN PATIENT KIOSK

Turn an existing all-in-one into a dedicated CareStack check-in and forms station, with Tailscale access for IT.

Pilot first. Code prepared for review; physical-device and CareStack validation remain required. Automatic boot opens Patient Connect. Staff still sign in, select Kiosk Mode and choose the office.

01 / Prepare

  • Back up the old computer before installing Debian.
  • Debian 13 / trixie, 64-bit x86.
  • SSH server + standard utilities; no desktop.
  • 4 GB RAM minimum; SSD preferred, healthy HDD acceptable.
  • Ethernet, keyboard and mouse for pilot. Touch-only typing is not implemented.

02 / Identify

Use a separate named IT administrator with sudo access.

Choose office and station 01–99:

Village Drive · Southcross · Schertz · Downtown · Dominion Crossing · Northern Oaks

Example:
schertz-kiosk-01

03 / Install from the private repository

Authorize the IT administrator’s GitHub SSH key first. Review the pilot revision before running it.

sudo apt update
sudo apt install -y git sudo
git clone git@github.com:kevcops/necd-kiosk.git
cd necd-kiosk
git switch codex/it-handoff-2026-10
sudo bash install.sh
sudo tailscale up
sudo reboot

After reboot: authenticate CareStack → Kiosk Mode → correct office → confirm the parent welcome screen.

SUPPORT + PILOT SIGN-OFF

At opening

Confirm the network, correct office and patient welcome screen. Sign in again after restart or CareStack session expiry.

Verify the previous patient’s information is cleared before the next family begins.

For IT

Restrict Tailscale access to approved IT. Test SSH keys and apply your SSH/firewall policy.

No remote desktop is included. Browser restarts clear login state and unfinished forms.

Remote commands

ssh IT_USERNAME@schertz-kiosk-01
sudo /opt/necd-kiosk/scripts/reset-kiosk.sh
sudo necd-support

Coordinate any restart with reception. The support command prints the archive and copy instructions. Review the report before sharing.

Before the first family uses it

  • Three cold boots reach the portal automatically.
  • Touch, typing, scrolling and signatures work on this model.
  • Test check-in and signed forms arrive correctly in CareStack.
  • Completed and abandoned sessions, Back and refresh protect patient separation.
  • Login and required forms work through the navigation allowlist.
  • Network/power recovery and Tailscale SSH have been tested.
  • Disk/swap protection, physical access and older local data reviewed.
  • Approved update and rollback tested; one clinic day observed.
Maintenance: Debian security updates are enabled; reboots are manual. Apply reviewed Git revisions during downtime. Restart Chromium to load browser updates, then have staff reauthenticate. Full instructions and limitations are in the README.
